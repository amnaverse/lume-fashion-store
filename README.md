# 🛍️ LUMÉ — Fashion E-Commerce Store

A luxury minimalist fashion storefront built with React.js, Vite, and Tailwind CSS.

**🔗 Live Demo:** https://amnaverse.github.io/lume-fashion-store/

## Features
- 🛒 Shopping cart using React Context API
- ❤️ Synchronized wishlist across the app
- 🗂️ Multi-tier category filtering
- 🎨 Clean, luxury minimalist design

## Tech Stack
- **Frontend:** React.js, Vite
- **Styling:** Tailwind CSS
- **State Management:** React Context API

## How to Run Locally
```bash
git clone https://github.com/amnaverse/lume-fashion-store.git
cd lume-fashion-store
npm install
npm run dev
```

The app runs on `http://localhost:5173`.
